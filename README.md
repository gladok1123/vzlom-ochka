# Яндекс Музыка — лёгкий плеер для Windows

Компактный плеер, который управляет Яндекс Музыкой, играющей в фоне.
Никакого Electron и тяжёлых фреймворков: чистый C++ + Win32 + Direct2D,
один `.exe` меньше мегабайта, без рантаймов и установки.

| | Этот плеер | Electron-обёртка |
|---|---|---|
| Размер exe | меньше 1 МБ | 50–150 МБ |
| Память | единицы МБ | 100+ МБ |
| Зависимости | только системные DLL Windows | Chromium + Node |
| Сборка | `build.bat` (CMake + VS 2022) | npm, node-gyp |

## Как это работает

У Яндекс Музыки в Windows нет официального десктопного приложения — это
веб-плеер на [music.yandex.ru](https://music.yandex.ru). Когда браузер играет
музыку, он регистрируется в Windows как **SMTC-сессия**
(System Media Transport Controls) и отдаёт системе:

- название трека, исполнителя, альбом;
- обложку;
- позицию и длительность, статус Play/Pause;
- команды Play / Pause / Next / Previous / Seek.

Плеер читает эти данные и рисует красивый интерфейс, а по клику шлёт команды
обратно. Никаких хаков, внедрения в браузер, парсинга страниц и токенов.

```
music.yandex.ru (Chrome / Edge / Firefox / Яндекс Браузер)
        │  SMTC: трек, обложка, позиция, команды
        ▼
Windows SMTC  ──►  YandexMusicPlayer.exe (Win32 + Direct2D + C++/WinRT)
```

## Быстрый старт

### Вариант 1 — скачать готовый exe

Готовый файл лежит в [Releases](https://github.com/gladok1123/vzlom-ochka/releases/latest):
**`YandexMusicPlayer.exe`** (~253 КБ). Сохраните куда угодно и запустите —
установка, рантаймы и VC++ Redistributable не нужны.

Свежие сборки каждой версии также лежат в **Actions** → запуск `build` →
артефакт `YandexMusicPlayer-x64`.

### Вариант 2 — собрать самому

Нужна **Visual Studio 2022** с компонентом *Desktop development with C++*
(внутри есть CMake и Windows SDK). Затем в папке проекта:

```bat
build.bat
```

Готовый файл: `build\Release\YandexMusicPlayer.exe`. VC++ Redistributable не
нужен — CRT слинкован статически, так что exe переносится на другой компьютер
одним файлом.

Либо вручную:

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
```

### 3. Пользоваться

1. Откройте [music.yandex.ru](https://music.yandex.ru) в браузере.
2. Нажмите **Play** на сайте.
3. Плеер сам подхватит трек: обложка, название, ползунок прогресса.

Дальше браузер трогать не нужно:

| Действие | Как |
|---|---|
| Play / Pause | жёлтая кнопка, двойной клик по обложке, `Ctrl+Alt+Space` |
| Следующий / предыдущий трек | кнопки ⏭ ⏮, `Ctrl+Alt+→` / `Ctrl+Alt+←` |
| Перемотка | клик по полоске прогресса |
| Громкость | ползунок или колесо мыши над окном |
| Mute | клик по иконке динамика, `Ctrl+Alt+M` |
| Перетащить окно | потянуть за любое пустое место |
| Свернуть в трей | кнопка `—` или `×` |
| Показать из трея | двойной клик по иконке в трее |
| Выход | правый клик по иконке в трее → «Выход» |

Окно: 460×212, тёмный градиент, скруглённые углы (Windows 11), всегда поверх
остальных окон, без кнопки в панели задач, корректно масштабируется при
125 % / 150 % / 200 % (Per-Monitor DPI v2).

## Если плеер не видит музыку

- **Музыка должна играть.** SMTC-сессия живёт, пока браузер воспроизводит
  трек. На паузе сессия может исчезнуть — плеер покажет подсказку.
- **Браузеры с поддержкой SMTC:** Chrome, Edge, Firefox, Яндекс Браузер,
  Opera, Brave, Vivaldi. Старые версии — обновите браузер.
- **Играет несколько браузеров/вкладок?** Нажмите круглую стрелку рядом с
  надписью «Источник: …» — плеер переключится на следующую сессию, выбор
  запоминается.
- **Команды не проходят?** Если SMTC-вызов не удался, плеер автоматически
  отправляет системные медиа-клавиши (`VK_MEDIA_*`) — они работают даже
  когда у браузера нет полноценной SMTC-сессии.
- **Колесо мыши** регулирует громкость, когда окно в фокусе: кликните по
  плееру один раз.

## Что внутри

```
src/main.cpp     окно, Direct2D-отрисовка, трей, горячие клавиши, очередь команд
src/smtc.h/.cpp  обёртка над SMTC: опрос сессий, метаданные, обложка, команды
src/volume.h     громкость системы через Core Audio API (SMTC её не умеет)
resources.rc     иконка приложения и версия в свойствах exe
CMakeLists.txt   сборка (C++17, статический CRT, windowsapp.lib для WinRT)
build.bat        сборка в один клик
```

Пара архитектурных решений, которые стоит знать:

- **SMTC трогает только один поток.** WinRT-объекты живут в MTA фонового
  потока; UI-поток (STA с циклом сообщений) лишь читает готовое состояние под
  мьютексом и кладёт команды в очередь. Иначе блокирующий `.get()` в STA
  легко подвешивает приложение.
- **Обложка читается только при смене трека** — `TryGetMediaPropertiesAsync`
  самый дорогой вызов SMTC, а опрос идёт каждые 400 мс.
- **Позиция экстраполируется** между опросами, поэтому ползунок едет плавно,
  не заставляя чаще дёргать систему.
- **Отрисовка через Direct2D** (аппаратное ускорение) в режиме по требованию:
  кадр рисуется только при изменении состояния, а не 60 раз в секунду.

### Выбор источника и развёрнутый режим

Нажмите на строку «Источник» в мини-плеере, чтобы выбрать медиасессию Windows; длинный список прокручивается колёсиком. Windows не сообщает SMTC PID или адрес вкладки: сессии различаются по приложению и отображаемому треку. При повторном запуске сохраняется приложение, но конкретную сессию одного и того же приложения может понадобиться выбрать заново.

Кнопка расширения открывает интерактивную Яндекс Музыку во встроенном WebView2; стрелка слева сверху возвращает мини-плеер. Для входа может потребоваться авторизация отдельно от браузера. Нужен установленный Microsoft Edge WebView2 Runtime. Кнопка закрепления переключает окно между рабочим столом и режимом поверх других окон; настройки также доступны в меню значка в трее. Время и перемотка зависят от данных и возможностей медиасессии: некоторые источники не поддерживают перемотку.

Для самостоятельной сборки встроенного браузера распакуйте NuGet-пакет `Microsoft.Web.WebView2` в `build/webview2` или укажите CMake `-DWEBVIEW2_SDK_DIR=путь`. Без SDK развёрнутый режим открывает сайт во внешнем браузере; используйте `-DYM_REQUIRE_WEBVIEW2=ON`, чтобы считать отсутствие SDK ошибкой сборки.
