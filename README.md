# Яндекс Музыка — лёгкий плеер для Windows

Компактный плеер, который управляет Яндекс Музыкой, играющей в фоне.
Никакого Electron и тяжёлых фреймворков: чистый C++ + Win32 + Direct2D,
один `.exe` без рантаймов.

| | Этот плеер | Electron-обёртка |
|---|---|---|
| Размер exe | ~0.5–1 МБ | 50–150 МБ |
| Память | единицы МБ | 100+ МБ |
| Зависимости | только Windows 10/11 | Chromium + Node |
| Сборка | `build.bat` (CMake + VS2022) | npm, node-gyp |

## Как это работает

У Яндекс Музыки в Windows нет официального десктопного приложения —
это веб-плеер на [music.yandex.ru](https://music.yandex.ru).
Когда браузер играет музыку, он сам регистрируется в Windows как
**SMTC-сессия** (System Media Transport Controls) и отдаёт системе:

- название трека, исполнителя, альбом;
- обложку;
- позицию и длительность, статус Play/Pause;
- команды Play / Pause / Next / Previous / Seek.

Плеер просто читает эти данные и рисует красивый интерфейс, а по клику
шлёт команды обратно. Никаких хаков, внедрений в браузер и парсинга страниц.

```
music.yandex.ru (Chrome/Edge/Firefox)
        │  SMTC: трек, обложка, позиция, команды
        ▼
Windows SMTC  ──►  YandexMusicPlayer.exe (Direct2D, акрил, трей)
```

## Быстрый старт

### 1. Собрать

Нужна **Visual Studio 2022** с компонентом *Desktop development with C++*
(там уже есть CMake и Windows SDK). Затем:

```bat
build.bat
```

Готовый файл: `build\Release\YandexMusicPlayer.exe` — его можно просто
запустить, копировать на флешку, кидать в автозагрузку. VC++ Redistributable
не нужен (CRT слинкован статически).

Если не хочется ставить Visual Studio — зайдите в раздел **Actions** этого
репозитория, откройте последнюю сборку `build` и скачайте артефакт
`YandexMusicPlayer-x64` (внутри готовый exe).

### 2. Пользоваться

1. Откройте [music.yandex.ru](https://music.yandex.ru) в Chrome, Edge или Firefox.
2. Нажмите **Play** на сайте.
3. Плеер сам подхватит трек: обложка, название, ползунок прогресса.

Дальше плеером можно управлять, не трогая браузер:

| Действие | Как |
|---|---|
| Play / Pause | кнопка ▶/⏸, двойной клик по обложке, `Ctrl+Alt+Space` |
| Следующий / предыдущий трек | кнопки ⏭/⏮, `Ctrl+Alt+→` / `Ctrl+Alt+←` |
| Перемотка | клик по ползунку прогресса |
| Громкость | ползунок, колесо мыши над окном, клик по иконке — mute |
| Mute | `Ctrl+Alt+M` |
| Перетаскивание окна | за любое пустое место |
| Скрыть в трей | кнопка `—` или `×` (выход — из меню иконки в трее) |
| Показать из трея | двойной клик по иконке в трее |

Окно компактное (460×212), всегда поверх остальных, без кнопки в панели задач,
со скруглёнными углами в Windows 11 и масштабированием под 125%/150%/200%.
Фон — тёмный градиент, нарисованный Direct2D: никакого акрила с размытием,
потому что он требует либо DWM-трюков, либо прозрачного swap-chain, а это
лишний вес и лишние баги. Колесо мыши работает, когда окно в фокусе
(достаточно один раз по нему кликнуть).

## Если плеер не видит музыку

- **Проверьте, что музыка реально играет.** SMTC-сессия появляется только
  во время воспроизведения. Поставьте трек на паузу — сессия может пропасть,
  плеер покажет подсказку.
- **Браузер должен поддерживать SMTC.** Chrome, Edge и Firefox — да.
  В редких случаях помогает перезагрузка вкладки.
- **Несколько браузеров/вкладок играют одновременно?** Нажмите кнопку
  с круглой стрелкой рядом с надписью «Источник: …» — плеер переключится
  на следующую сессию. Выбор запоминается.
- **SMTC выключен в Windows?** В Windows 10/11 он включён по умолчанию.
  Если команды не проходят, плеер автоматически шлёт системные
  медиа-клавиши (`VK_MEDIA_*`) как запасной вариант.

## Структура проекта

```
src/main.cpp    окно, Direct2D-отрисовка, трей, горячие клавиши, Core Audio
src/smtc.h/.cpp обёртка над SMTC (WinRT): опрос сессий, команды, обложка
src/volume.h    громкость системы через Core Audio API
CMakeLists.txt  сборка (C++17, статический CRT)
build.bat       сборка в один клик
```
